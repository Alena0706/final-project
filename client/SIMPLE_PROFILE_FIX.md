# Простое исправление для ProfileSection

## ✅ Готово! Редактируемые placeholder в ProfileSection

Я сделал простое решение прямо в `ProfileSection.tsx` без сложных хуков и утилит.

## Что изменилось

### 1. Функция `getFieldValue`

Показывает placeholder как значение по умолчанию когда поле в режиме редактирования и пустое.

### 2. Обработчики событий

- `handleInputClick` - выделяет весь текст при клике на placeholder
- `handleInputKeyDown` - очищает поле при нажатии клавиши на placeholder
- `handleInputChange` - правильно обрабатывает ввод

## Как это работает

1. **При клике на кнопку редактирования**: поле переходит в режим редактирования
2. **Если поле пустое**: показывается placeholder как значение
3. **При клике на поле**: весь текст выделяется
4. **При нажатии клавиши**: поле очищается для ввода нового текста
5. **При вводе**: placeholder заменяется на новый текст

## Пример использования

```tsx
// В ProfileSection.tsx уже все настроено
// Просто используйте компонент как обычно

<ProfileSection />
```

## Что происходит автоматически

- Placeholder отображается как значение по умолчанию
- При клике весь текст выделяется
- При нажатии клавиши поле очищается
- Можно редактировать только часть текста
- При очистке placeholder восстанавливается

## Никаких дополнительных настроек!

Все работает автоматически в существующем компоненте ProfileSection.
