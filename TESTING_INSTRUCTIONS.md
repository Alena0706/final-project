# Инструкция по тестированию

## 🚀 Запуск приложения

### 1. Запустите сервер (порт 3001)
```bash
cd server
PORT=3000 node src/server.js
```

### 2. Запустите клиент (порт 5173)
```bash
cd client
npm run dev
```

- **Пароль**: `password`

### Пользователь
- **Email**: `user@test.com`

- **Доступ**: только профиль и счета

## 🧪 Тестирование функционала

### 1. Вход в систему
1. Откройте `http://localhost:5173`
2. Нажмите "Вход"
3. Войдите с любым тестовым аккаунтом

### 2. Тестирование как пользователь
1. Перейдите в "Профиль"
2. Проверьте вкладки:
   - **Пополнение кошелька** - баланс и транзакции
   - **Мои счета** - просмотр и оплата счетов
   - **Уведомления** - просмотр уведомлений

### 3. Тестирование как администратор
1. Войдите как `admin@test.com`
2. В навбаре появится ссылка "Админка"
3. Перейдите в админку и проверьте:
   - **Счета** - просмотр всех счетов
   - **Уведомления** - просмотр всех уведомлений
   - **Создать счет** - форма с дропдауном пользователей
   - **Отправить уведомление** - массовая рассылка

## 🐛 Устранение проблем

### Если API возвращает 404
1. Проверьте, что сервер запущен на порту 3001
2. Проверьте, что фронтенд запущен на порту 5173
3. Проверьте конфигурацию прокси в `vite.config.ts`

### Если не работает авторизация
1. Проверьте, что база данных заполнена тестовыми данными
2. Убедитесь, что JWT_SECRET настроен
3. Проверьте cookies в браузере

### Если не отображается админка
1. Войдите как администратор (`admin@test.com`)
2. Проверьте, что в навбаре есть ссылка "Админка"
3. Убедитесь, что пользователь имеет роль `admin: true`

## ✅ Ожидаемые результаты

### Для пользователя
- Видит свой баланс и транзакции
- Может просматривать и оплачивать счета
- Получает уведомления о новых счетах и платежах

### Для администратора
- Видит ссылку "Админка" в навбаре
- Может создавать счета для пользователей
- Может отправлять уведомления всем пользователям
- Видит все счета и уведомления в системе

## 🎯 Основные функции для тестирования

1. **Создание счета** - админ выбирает пользователя из дропдауна
2. **Оплата счета** - пользователь оплачивает счет с баланса
3. **Отправка уведомлений** - админ отправляет массовые уведомления
4. **Просмотр истории** - все операции сохраняются и отображаются
