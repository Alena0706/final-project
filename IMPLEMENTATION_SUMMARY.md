## 🔧 Технические детали

### Модели данных
- **Invoice** - счета с полями: userId, amount, description, status, dueDate, paidAt, createdBy, isAutoGenerated
- **Payment** - платежи с полями: invoiceId, walletId, amount, status
- **Transaction** - транзакции кошелька с полями: walletId, amount, type, status, description, adminId
- **Notification** - уведомления с полями: userId, type, title, message, isRead, sentAt
- **Wallet** - кошельки с полями: userId, balance

### Типы уведомлений
- `invoice_reminder` - Напоминание о счете
- `payment_reminder` - Напоминание об оплате
- `invoice_generated` - Создан новый счет
- `payment_received` - Получен платеж
- `manual` - Ручное уведомление от администратора

### Статусы счетов
- `pending` - Ожидает оплаты
- `paid` - Оплачен
- `overdue` - Просрочен
- `cancelled` - Отменен

### Безопасность
- JWT аутентификация для всех защищенных endpoints
- Проверка ролей для админских функций
- Валидация данных на всех уровнях
- Проверка прав доступа к ресурсам

## 📋 API Endpoints

### Кошелек
- `GET /api/wallet` - получить кошелек
- `GET /api/wallet/transactions` - история транзакций
- `POST /api/wallet/topup` - пополнить (админ)
- `GET /api/wallet/all` - все кошельки (админ)

### Счета
- `POST /api/invoices` - создать счет (админ)
- `GET /api/invoices/my` - мои счета
- `GET /api/invoices/all` - все счета (админ)
- `GET /api/invoices/:id` - детали счета
- `POST /api/invoices/:id/pay` - оплатить счет
- `PATCH /api/invoices/:id/cancel` - отменить счет (админ)

### Уведомления
- `GET /api/notifications/my` - мои уведомления
- `GET /api/notifications/all` - все уведомления (админ)
- `GET /api/notifications/unread-count` - количество непрочитанных
- `PATCH /api/notifications/:id/read` - отметить как прочитанное
- `PATCH /api/notifications/mark-all-read` - отметить все как прочитанные
- `DELETE /api/notifications/:id` - удалить уведомление
- `POST /api/notifications/broadcast` - отправить всем (админ)
- `POST /api/notifications/send` - отправить пользователю (админ)

## 🚀 Как запустить

1. Установить зависимости:
```bash
cd server && npm install
```

2. Настроить переменные окружения:
```env
EMAIL_USER=your-email@gmail.com
EMAIL_PASSWORD=your-app-password
CLIENT_URL=http://localhost:5173
```

3. Запустить сервер:
```bash
npm start
```

4. Запустить тесты:
```bash
node test-api.js
```
