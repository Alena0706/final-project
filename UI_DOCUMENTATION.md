# Документация пользовательского интерфейса

## 📱 Где отображаются счета и уведомления

### Для обычных пользователей

#### 1. **Страница профиля** (`/profile`)
Доступна через навигацию "Профиль" в шапке сайта.

**Вкладки:**
- **Пополнение кошелька** - управление балансом и история транзакций
- **Мои счета** - просмотр и оплата счетов
- **Уведомления** - просмотр уведомлений от системы
- **Персональные данные** - редактирование профиля
- **Изменение пароля** - смена пароля

#### 2. **Мои счета** (`/profile/invoices`)
- 📄 Список всех счетов пользователя
- 🔍 Фильтрация по статусу (все, ожидает оплаты, оплачен, просрочен, отменен)
- 💳 Оплата счетов одним кликом
- 📊 Детальная информация о каждом счете
- 📈 История платежей по счету
- 📄 Пагинация для больших списков

**Функции:**
- Просмотр деталей счета (сумма, описание, срок оплаты)
- Оплата счета с баланса кошелька
- Просмотр истории платежей
- Фильтрация и поиск

#### 3. **Уведомления** (`/profile/notifications`)
- 🔔 Список всех уведомлений
- 🔍 Фильтрация по статусу (все, непрочитанные, прочитанные)
- ✅ Отметка уведомлений как прочитанных
- 🗑️ Удаление уведомлений
- 📊 Счетчик непрочитанных уведомлений
- 📄 Пагинация

**Типы уведомлений:**
- 📄 `invoice_generated` - Новый счет
- ✅ `payment_received` - Платеж получен
- ⏰ `invoice_reminder` - Напоминание о счете
- 💳 `payment_reminder` - Напоминание об оплате
- 📢 `manual` - Ручное уведомление от админа

### Для администраторов

#### 1. **Админская панель** (`/admin`)
Доступна через ссылку "Админка" в навигации (только для админов).

**Основные функции:**
- 📊 Обзор всех счетов и уведомлений
- ➕ Создание новых счетов
- 📢 Отправка уведомлений
- 👥 Управление пользователями

#### 2. **Управление счетами**
- 📋 Просмотр всех счетов в системе
- ➕ Создание счетов для пользователей
- ❌ Отмена счетов
- 🔍 Фильтрация по пользователю и статусу
- 📊 Детальная информация о каждом счете

**Форма создания счета:**
- ID пользователя
- Сумма счета
- Описание
- Срок оплаты
- Автоматическое создание уведомления

#### 3. **Управление уведомлениями**
- 📋 Просмотр всех уведомлений в системе
- 📢 Массовая рассылка всем пользователям
- 👤 Отправка конкретному пользователю
- 📧 Отправка по email
- 🔍 Фильтрация по типу и статусу

**Типы рассылки:**
- **Всем пользователям** - массовая рассылка
- **Только пользователям** - исключая админов
- **Только админам** - для внутренних уведомлений
- **Конкретному пользователю** - персональные уведомления

## 🎨 Дизайн и UX

### Цветовая схема
- **Основной цвет**: Градиент синий (#667eea → #764ba2)
- **Успех**: Зеленый (#28a745)

- **Ошибка**: Красный (#dc3545)

- 🟡 **Ожидает оплаты** - желтый
- 🟢 **Оплачен** - зеленый
- 🔴 **Просрочен** - красный
- ⚫ **Отменен** - серый

### Статусы уведомлений
- 🔴 **Непрочитанное** - красная точка + жирный шрифт
- ⚫ **Прочитанное** - обычный шрифт

## 🚀 Как использовать

### Для пользователей:
1. Войдите в систему
2. Перейдите в "Профиль"
3. Выберите вкладку "Мои счета" для просмотра счетов
4. Выберите вкладку "Уведомления" для просмотра уведомлений
5. Оплачивайте счета и управляйте уведомлениями

### Для администраторов:
1. Войдите как администратор
2. Перейдите в "Админка"
3. Используйте табы для навигации между функциями
4. Создавайте счета и отправляйте уведомления

## 📧 Email уведомления

Система автоматически отправляет красивые HTML email при:
- Создании нового счета
- Успешной оплате счета
- Ручной отправке уведомлений админом

Все email имеют единый дизайн с брендингом "Твой взгляд".
