# Email уведомления - Руководство по использованию

## 🎉 Что реализовано

✅ **Автоматическая отправка приветственного email** при регистрации пользователя  
✅ **Красивый HTML шаблон** с градиентами и кнопками  
✅ **Текстовая версия** для старых почтовых клиентов  
✅ **Обработка ошибок** - регистрация не прерывается, если email не отправился  
✅ **Логирование** всех операций с email

## 📁 Созданные файлы

- `src/services/email.service.js` - сервис для отправки email
- `test-email.js` - тестовый файл для проверки настройки
- `EMAIL_SETUP.md` - инструкции по настройке Gmail
- `EMAIL_USAGE.md` - это руководство

## 🔧 Настройка

### 1. Переменные окружения (.env)

```env
EMAIL_USER=your-email@gmail.com
EMAIL_PASSWORD=your-app-password
CLIENT_URL=http://localhost:3000
```

### 2. Настройка Gmail

1. Включите двухфакторную аутентификацию
2. Создайте пароль приложения для "Почта"
3. Используйте этот пароль в EMAIL_PASSWORD

## 🧪 Тестирование

### Проверка настройки email

```bash
node test-email.js
```

### Тестирование регистрации

1. Запустите сервер: `npm run dev`
2. Отправьте POST запрос на `/auth/signup` с данными пользователя
3. Проверьте почту - должен прийти приветственный email

## 📧 Шаблоны email

### Приветственное письмо

- **Тема**: "🎉 Добро пожаловать! Регистрация прошла успешно"
- **Содержание**: Красивый HTML с градиентами, кнопкой входа
- **Отправляется**: При каждой успешной регистрации

### Сброс пароля (готов к использованию)

- **Тема**: "🔐 Сброс пароля"
- **Содержание**: Ссылка для сброса пароля
- **Отправляется**: При запросе сброса пароля

## 🚀 Использование в коде

### Отправка приветственного email

```javascript
const EmailService = require('./services/email.service');

// Автоматически вызывается в AuthService.signup()
await EmailService.sendWelcomeEmail('user@example.com', 'Имя пользователя');
```

### Отправка email сброса пароля

```javascript
await EmailService.sendPasswordResetEmail('user@example.com', 'Имя', 'reset-token');
```

### Проверка подключения

```javascript
const isConnected = await EmailService.verifyConnection();
```

## 🔍 Логирование

Все операции с email логируются в консоль:

- ✅ Успешная отправка
- ❌ Ошибки отправки
- 🔗 Проверка подключения

## 🛠️ Настройка для продакшена

### 1. Используйте надежный email провайдер

- SendGrid (рекомендуется)
- Mailgun
- AWS SES

### 2. Настройте домен

- Добавьте SPF, DKIM, DMARC записи
- Используйте поддомен для email (например, noreply@yourdomain.com)

### 3. Обработка ошибок

- Добавьте очередь для повторной отправки
- Сохраняйте неудачные отправки в базу данных
- Настройте мониторинг

## 🆘 Устранение проблем

### Email не отправляется

1. Проверьте переменные окружения
2. Убедитесь, что используете пароль приложения
3. Проверьте подключение к интернету
4. Запустите `node test-email.js`

### Ошибка "Invalid login"

- Проверьте EMAIL_USER и EMAIL_PASSWORD
- Убедитесь, что включена двухфакторная аутентификация

### Email попадает в спам

- Настройте SPF, DKIM, DMARC
- Используйте надежный email провайдер
- Избегайте спам-слов в теме и содержании
